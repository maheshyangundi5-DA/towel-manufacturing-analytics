
# Towel Manufacturing Analytics

### End-to-End Data Analytics Project | Power BI | SQL | Python | Excel

## 📌 Project Overview

Towel Manufacturing Analytics is an end-to-end data analytics project focused on analyzing business operations and performance in the towel manufacturing industry.

The project aims to transform raw manufacturing and business data into meaningful insights that help management monitor operational performance, evaluate business trends, identify improvement opportunities, and support data-driven decision-making.

Using data analysis and interactive Power BI dashboards, this project explores production performance, product trends, customer behavior, sales performance, and delivery operations.

## 🎯 Business Problem

Manufacturing businesses generate large amounts of operational and transactional data. However, without proper analysis and visualization, it becomes difficult to monitor performance, identify inefficiencies, and make informed business decisions.

This project addresses the need for a centralized analytical solution to:

- Monitor manufacturing and business performance.
- Analyze customer and product performance.
- Track order delivery status.
- Understand sales and revenue trends.
- Identify business improvement opportunities.
- Support management decision-making through interactive dashboards.

## 🎯 Project Objectives

- Analyze overall business and operational performance.
- Evaluate customer distribution and customer activity.
- Monitor product and category performance.
- Analyze sales and revenue trends.
- Evaluate order delivery performance.
- Identify important business patterns and trends.
- Build interactive dashboards for business stakeholders.

## 📊 Key Performance Indicators (KPIs)

The project focuses on analyzing important business performance indicators, including:

| KPI | Description |
| --- | --- |
| Total Customers | Total number of unique customers |
| Active Customers | Number of customers with active status |
| Inactive Customers | Number of customers with inactive status |
| Total Orders | Total number of orders |
| Total Sales | Overall sales generated |
| Total Revenue | Total revenue generated |
| Average Order Value | Average revenue per order |
| Delivered Orders | Number of successfully delivered orders |
| Delayed Orders | Number of orders delivered late |
| In-Transit Orders | Number of orders currently in transit |
| Returned Orders | Number of returned orders |

## 🚀 Business Recommendations

Based on the analytical findings, management can consider the following actions:

1. **Customer Management:** Focus on customer retention and engagement strategies.
2. **Product Performance:** Prioritize high-performing products and investigate low-performing categories.
3. **Delivery Optimization:** Investigate delayed deliveries and improve order fulfillment processes.
4. **Returns Management:** Analyze return patterns to identify possible product or logistics issues.
5. **Business Monitoring:** Use interactive dashboards to monitor KPIs and support regular performance reviews.
